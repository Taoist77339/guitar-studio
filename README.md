# Practice Studio

An acoustic guitar practice app that runs in the browser and installs like a regular app.

- **Tuner**: live pitch detection from your microphone, with reference tones for all six strings
- **Chords**: 16 beginner chords with finger diagrams; tap any chord to hear it
- **Rhythm**: metronome with tap tempo, three strum patterns and common progressions it can play along
- **Lesson path**: eight steps from posture to the folk strum, with progress saved on your device

Open it at https://taoist77339.github.io/guitar-studio/ and choose **Install** (desktop Chrome/Edge) or **Add to Home Screen** (phone). It works offline once installed.

No build step: it is one `index.html` plus a manifest and a service worker.
